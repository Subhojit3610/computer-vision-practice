# Computer Vision Practice

Two computer vision projects built for Kaggle competitions in a deep learning course, using transfer learning on a single Tesla T4 GPU.

| Project | Task | Model | Kaggle score (private / public) |
|---|---|---|---|
| [Image classification](image-classification/) | 10 taxonomic groups of animals, plants and fungi | ConvNeXt-Small (PyTorch) | weighted F1 0.9321 / 0.9566 |
| [Mosquito detection](object-detection/) | Detect mosquitoes in low-light phone photos and classify 6 species | YOLOv8m (Ultralytics) | mAP 0.83152 / 0.82802 |

Each folder has its own README, the notebooks with full outputs, and result charts. Competition data is not included.
